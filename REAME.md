# FoxNovel - Plataforma de Novela Ligeras
 ¡ Bienvenido a **FoxNovel**! Este proyecto es el nucleo de una plataforma de lectura de novela ligeras y traduccion manual en espanol.
 
 Siguiendo la estrategia **"Si no tenemos sitio web, no tenemos app"**, este repositorio php actual como el motor central que almacena y gestiona todo el contenido que posteriormente alimentara a la aplicacion movil en react Native.

 ---
 ## Caracteristicas Principales
 * **Paleta Visual:** interfaz disenada con tonos calidos de naranja oxido, fuego y cremas suaves
